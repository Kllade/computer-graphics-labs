## ADDED Requirements

### Requirement: Платформа и графический стек
Программа MUST использовать C++, Vulkan, GLFW и ImGui и запускаться на macOS через MoltenVK.

#### Scenario: Сборка и запуск
- **WHEN** пользователь выполняет команды сборки и запуска из README
- **THEN** открывается окно приложения с фигурой и интерфейсом
- **AND** ошибки валидации Vulkan отсутствуют

### Requirement: Правильный икосаэдр
Программа MUST рисовать исходную сетку правильного икосаэдра: 12 вершин, 30 рёбер и 20 равносторонних треугольных граней с учётом глубины.

#### Scenario: Исходная геометрия
- **WHEN** построена сетка до пользовательских трансформаций
- **THEN** все вершины лежат на одной описанной сфере и все рёбра равны
- **AND** каждое ребро принадлежит двум граням

### Requirement: Переключение проекции
Программа MUST позволять выбирать перспективную и ортографическую проекции через интерфейс во время работы.

#### Scenario: Смена проекции
- **WHEN** пользователь меняет режим проекции
- **THEN** изображение обновляется без перезапуска
- **AND** геометрия и пользовательские трансформации сохраняются

### Requirement: Аффинные преобразования
Программа MUST предоставлять изменение позиции, поворота и масштаба объекта по трём осям.

#### Scenario: Изменение параметра
- **WHEN** пользователь меняет Position, Rotation или Scale
- **THEN** соответствующее преобразование выбранного объекта видно в следующем кадре

### Requirement: Управляемая анимация
Программа MUST поддерживать пространственное движение и вращение, паузу, продолжение, изменение скорости и параметров траектории.

#### Scenario: Пауза и продолжение
- **WHEN** пользователь останавливает анимацию и затем продолжает её
- **THEN** время анимации продолжается с сохранённой фазы
- **AND** сама пауза не изменяет позу объекта

#### Scenario: Изменение траектории
- **WHEN** пользователь меняет скорость, радиус или высоту траектории
- **THEN** движение определяется новыми параметрами

### Requirement: Выбор цвета
Программа MUST предоставлять выбор RGB-цвета объекта через ImGui ColorEdit.

#### Scenario: Однотонный цвет
- **WHEN** пользователь меняет цвет при отключённых цветах вершин и подсветке
- **THEN** фигура отображается выбранным цветом

### Requirement: Процедурные цвета вершин
Программа MUST вычислять цвета вершин процедурно из их локальных позиций и умножать их на выбранный пользователем цвет.

#### Scenario: Умножение цветов
- **WHEN** включены цвета вершин и выбран белый основной цвет
- **THEN** видны процедурные цвета и их интерполяция

#### Scenario: Изменение основного цвета
- **WHEN** основной цвет изменяется при включённых цветах вершин
- **THEN** итоговый цвет вычисляется покомпонентным умножением

### Requirement: Несколько объектов и наборов дескрипторов
Программа MUST отображать больше одного объекта, используя больше одного VkDescriptorSet с индивидуальными данными объектов.

#### Scenario: Независимое редактирование
- **WHEN** пользователь изменяет параметры выбранного экземпляра
- **THEN** параметры других экземпляров сохраняются
- **AND** перед каждым draw используется набор данных соответствующего экземпляра

### Requirement: Безопасная работа с ресурсами
Программа MUST обновлять GPU-данные с учётом синхронизации и освобождать созданные Vulkan-ресурсы после завершения их использования.

#### Scenario: Завершение приложения
- **WHEN** пользователь закрывает окно
- **THEN** работа GPU завершается до уничтожения её ресурсов
- **AND** программа освобождает созданные ею буферы, дескрипторные ресурсы и pipeline
