# Лабораторная №1: интерактивная 3D-сцена на Vulkan

## Зачем

Нужно выполнить лабораторную «Основы 3D-графики»: построить фигуру,
преобразовать её в пространстве и спроецировать на экран. Работа должна
демонстрировать связь между геометрией, матрицами и графическим конвейером.

Студент: Рахимов Михаил Юрьевич, М8О-301БВ-24. Номер в списке — 23.
При 12 вариантах `((23 - 1) % 12) + 1 = 11`: правильный икосаэдр.

## Исходные условия

Используем стартовый проект преподавателя на C++ с Vulkan, GLFW и ImGui.
Он предоставляет окно, Vulkan-устройство, swapchain, глубину, инфраструктуру
интерфейса и цикл вызовов `initialize`, `update`, `render`, `shutdown`.
Разработку ведём на macOS с Vulkan SDK и MoltenVK.

Сначала нужно проверить сборку шаблона и запись простого render pass
с очисткой изображения. После этого добавлять геометрию и задания по очереди,
с проверкой результата после каждого законченного этапа.

## Что разработать

1. Программно построить правильный икосаэдр и вывести его через Vulkan.
2. Добавить переключение перспективной и ортографической проекций.
3. Дать пользователю изменять позицию, поворот и масштаб по трём осям.
4. Добавить пространственную анимацию с паузой, скоростью и параметрами траектории.
5. Добавить выбор основного цвета и процедурные цвета вершин.
6. Вывести несколько объектов с отдельными `VkDescriptorSet`.
7. Подготовить команды сборки, описание кода и отчёт после одобрения программы.

## Порядок получения результата

| Уровень | Законченный результат |
|---|---|
| Базовый, на 3 | Один правильный икосаэдр с корректной 3D-проекцией и глубиной |
| Дополнительные задания 1–5, на 4 | Две проекции, трансформации, анимация, выбор цвета, цвета вершин |
| Дополнительное задание 6, на 5 | Несколько объектов с отдельными наборами дескрипторов |

Это объём требований лабораторной. Итоговую оценку определяет преподаватель
с учётом срока и защиты.

## Принципы реализации

- Одна ответственность на файл: геометрия, математика, состояние, Vulkan-команды, шейдеры.
- Обычные функции и небольшие структуры данных с ясными именами.
- Конкретные Vulkan-вызовы остаются видимыми в коде приложения.
- Повторяющиеся создание буфера и загрузку шейдера вынести в `graphics.hpp/.cpp`.
- Комментарии объясняют математическое соглашение и назначение этапа.
- Добавлять возможности только после проверки предыдущего этапа.

## Границы

Предусматриваются программная модель фигуры и индексная отрисовка.
Загрузка OBJ, текстуры, универсальный движок и полноценные модели освещения
не входят в условия первой лабораторной. Простую подсветку граней можно добавить
для различимости формы и отключать при демонстрации цвета.

## Условия приёмки

Программа собирается на macOS, работает в реальном времени и выполняет
[функциональные требования](specs/lab1/spec.md). Пользователь может показать
каждый дополнительный пункт через интерфейс. Проекции, геометрия и анимация
проходят математические проверки; обычный запуск не выдаёт ошибок валидации.
Студент может проследить путь от массива вершин до `vkCmdDrawIndexed` и шейдеров.
